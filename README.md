# Human validation dashboard

Results of two human-validation studies of an LLM's 1-7 ratings of Reddit comments on six categories of how people talk about generative AI:

- **Agree/Disagree study**: 30 raters, the same 30 comments.
- **1-7 rating study**: 32 raters, 180 comments, 3-4 raters per comment.
- **Compare**: the same statistics side by side (different comments and raters; no comment has been rated in both formats yet).

Open `index.html` (it loads d3 from cdnjs). The page contains aggregate numbers only: no comment text and no rater identifiers.
Snapshot of the 13 and 19 November 2026 Qualtrics exports.
